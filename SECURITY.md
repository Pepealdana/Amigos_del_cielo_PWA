# Política de seguridad — Amigos del Cielo

## Reportar una vulnerabilidad

Si encuentras una vulnerabilidad de seguridad en Amigos del Cielo, por favor evita publicar detalles técnicos en una issue pública.

Puedes reportarla por correo:

**pepealdanagomez@hotmail.com**

Incluye, si es posible:

- una descripción clara del problema;
- los pasos para reproducirlo;
- la versión de la aplicación;
- capturas de pantalla o evidencia técnica no sensible.

No envíes contraseñas, tokens, claves privadas ni otros secretos.

## Alcance

Esta política aplica al código publicado en este repositorio y a la aplicación web publicada desde él.

Las sugerencias de contenido, nuevos santos y mejoras funcionales deben enviarse mediante la sección **Participa** de la aplicación.

## Buenas prácticas del proyecto

El repositorio público no debe contener:

- contraseñas;
- tokens;
- claves API privadas;
- credenciales de servicios;
- cadenas de conexión con credenciales;
- certificados o claves privadas.

Si una credencial se publica accidentalmente, debe considerarse comprometida y revocarse o sustituirse inmediatamente.
